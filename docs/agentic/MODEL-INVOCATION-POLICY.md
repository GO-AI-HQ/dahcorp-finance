# Finance Model Invocation Policy

Do not call every model on every question. Invoke a role when it materially adds value and record why.

Strategy workflow: OpenAI proposal and Claude independent challenge are the default two-model pattern for material portfolio decisions; Perplexity is invoked for external research/verification; Grok is invoked for tactical/adversarial work within its current authority. Planning and research may use retained evidence; execution requires fresh broker-authoritative revalidation.

Model version changes never widen authority.
