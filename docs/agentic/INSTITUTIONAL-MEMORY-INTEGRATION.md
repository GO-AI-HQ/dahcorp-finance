# Agentic ↔ Institutional Memory Integration

`docs/ai/` records what DAHCorp Finance is, how it evolved and what is authoritative. `docs/agentic/` records how JARVIS/models read that truth, divide work, access MCP capabilities, request authorization and produce receipts.

Every material future PR must ask both: what institutional knowledge changed, and did any model role/MCP/schema/authority/approval/observability contract change? If yes, update both layers before subsequent agents treat the change as baseline.
